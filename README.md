# Tienda de Barrio API

Proyecto realizado para el programa ADSO del SENA.

## Descripción
Aplicación desarrollada con Node.js para gestionar los productos de una tienda de barrio.

## Funcionalidades
- Buscar productos por ID.
- Listar productos agotados.
- Consultar el valor total del inventario.
- Listar productos por categoría.
- Formatear precios en pesos colombianos.

## Tecnologías
- JavaScript
- Node.js
- npm
- Git y GitHub
- picocolors
